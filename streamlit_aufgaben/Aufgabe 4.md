# Aufgabe 4:

## Reflexion:
### 1. Anwendungsfall Streamlit
Streamlit würde ich für ein schnelles Daten-Dashboard verwenden, zum Beispiel zur Darstellung von Verkaufszahlen oder Analyseergebnissen.

### 2. Anwendungsfall Django / FastAPI
Django oder FastAPI würde ich bevorzugen, wenn eine größere Webanwendung mit Benutzerverwaltung, Datenbanklogik und mehreren API-Endpunkten entwickelt werden soll.

### 3. Begündung
Der Grund ist, dass Streamlit sehr schnell für interaktive Daten-Apps ist, während Django und FastAPI besser für komplexe produktive Websysteme geeignet sind.
